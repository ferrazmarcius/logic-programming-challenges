# 🧠 Desafios de Lógica de Programação

Este repositório centraliza pequenos projetos e desafios de código criados para praticar lógica de programação, manipulação de dados e estruturas condicionais, demonstrando versatilidade em múltiplas linguagens.

## 📁 Estrutura do Monorepo

| Diretório | Linguagem | Descrição |
| :--- | :---: | :--- |
| **`javascript-classificador-de-heroi/`** | JavaScript | Script simples para classificar o nível de um herói com base em sua quantidade de Experiência (XP). |
| **`python-validador-de-cartoes/`** | Python | Algoritmo para validar e identificar a bandeira de um número de cartão de crédito, focado em lógica condicional e manipulação de strings. |

## 🛠️ Tecnologias Utilizadas

* **Python 3**
* **JavaScript**
